# Zotero 笔记摘要列（Note Preview Column）

![插件图标](icons/note-preview-column.svg)

适用于 Zotero 10.0.x。插件在文献列表中增加“笔记摘要”列，让父条目直接显示其子笔记的纯文本内容，无需展开条目。

## 功能

- 普通文献条目直接显示子笔记摘要；
- 独立笔记显示自身内容；
- 独立 PDF/附件显示附件笔记，适用于尚未成功识别元数据的中文 PDF；
- 支持合并全部、第一条或最近修改的笔记；
- 自定义摘要长度和多笔记分隔符；
- 自动将 Zotero 笔记 HTML 转换为单行纯文本；
- 子笔记发生变化时自动刷新父条目。

## 安装

1. 在 Zotero 中打开“工具 → 插件”。
2. 点击齿轮按钮，选择“从文件安装插件”。
3. 选择 `dist/zotero-note-preview-column-1.1.0.xpi`。
4. 回到文献列表，右键单击表头，勾选“笔记摘要”。

## 设置

在 Zotero 设置的“笔记摘要列”页面中，可以选择：

- 合并全部、第一条或最近修改的笔记；
- 摘要最大字符数（40–5000）；
- 多条笔记之间的分隔符。

## 行为说明

- 普通文献条目：显示其所有子笔记的摘要。
- 独立笔记或展开后的子笔记：显示该笔记本身的摘要。
- 独立 PDF/其他附件：显示附件自身的笔记字段。
- PDF 高亮/批注不属于普通子笔记，因此不会自动混入此列；可以先用 Zotero 的“从批注添加笔记”生成子笔记。
- HTML 格式会转换为单行纯文本，图片不会显示。

## 中文 PDF 无法识别成文献条目

这不是本插件造成的。Zotero 原生的 PDF 元数据检索对中文文献支持有限，中文 PDF 常会以“独立附件”形式留下，而没有标题、作者、期刊等父条目。

推荐安装兼容 Zotero 10 的 [茉莉花（Jasminum）](https://zotero-chinese.github.io/user-guide/plugins/jasminum)：

1. 尽量将 PDF 文件名改成完整中文论文标题；
2. 在茉莉花设置中开启中文 PDF/CAJ 元数据识别，并更新中文转换器；
3. 右键独立 PDF，选择“茉莉花抓取/知网助手 → 抓取期刊元数据”；
4. 自动结果仍应人工核对。

本插件 1.1.0 即使遇到尚未识别的独立中文 PDF，也能显示该附件自身的笔记；但它不会代替茉莉花创建完整书目元数据。

## 兼容性

清单限定为 Zotero `10.0` 至 `10.0.*`，已针对 Zotero 10.0.2（64 位）编写。

## 从源码构建

Windows PowerShell：

```powershell
.\build.ps1
```

生成的 XPI 位于 `dist/`。XPI 本质上是根目录包含 `manifest.json` 与 `bootstrap.js` 的 ZIP 文件。
